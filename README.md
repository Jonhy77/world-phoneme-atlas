# World Phoneme Atlas

An interactive atlas of the speech sounds of the world's languages. It shows which IPA sounds each language uses, sorted by manner and place of articulation, with recordings, animated articulation diagrams and a comparison tool for language learners.

Open `index.html` in a browser (serve the folder over HTTP so the audio files can load, for example `python -m http.server`).

## What's in it

- **Top 30 languages** (Ethnologue 2026, total speakers) as a checklist of sounds, with hand-checked inventories and cited corrections where the source data had clear errors.
- **All 2,175 languages** with a documented phoneme inventory in PHOIBLE 2.0, filterable by family, region and sound, sortable by inventory size or native speakers.
- **280 sound columns**: every symbol on the official IPA chart plus every variant used by at least 1% of languages, grouped by manner (plosive, nasal, trill, tap, fricative, approximant, affricate, ejective, implosive, click…) and place.
- **Sound panels**: an animated side view of the mouth for every sound, a "how to make it" description, a reference recording (152 sounds) and a native-speaker example word (233 sounds), each verified against its Wiktionary IPA transcription.
- **Compare**: line up one or more languages you speak against a language you are learning, with the sounds to practise and the closest sound you already know.
- **Language panels**: full inventory, missing sounds, inventory alternatives, native speaker counts, and a family tree (Glottolog) with the chain of ancestor languages (Wiktionary).
- **Glossary** of phonetic terms with clickable examples, a merge-variants view, axis swapping and row/column highlighting.

## Rebuilding

The page is generated by the scripts in `build/` (Python 3, standard library only):

```bash
bash build/fetch_data.sh   # downloads PHOIBLE, Glottolog, ISO 639-3, Wikidata and Wiktionary data into build/data/
bash build/make.sh         # rebuilds index.html and audio/
```

`build/selections/` holds the chosen example words and recordings with their credits, so a rebuild does not need to search Wiktionary again. The scripts that made those selections (`verify.py`, `auto.py`, `pick_words.py`, `fetch_words.py`, `finalize_words.py`, `kaikki_stream.py`, `audio.py`) are included for reference.
